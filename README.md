# AAA Healthcare Agency Ltd — Homecare App

This repository is the shared development workspace for a new homecare application. The application is in planning.

## First milestone

Build a working preview of the office dashboard and carer visit view. Use fictional clients and carers to demonstrate assigning a visit, recording its completion and reviewing exceptions.

## Working on the project

Track features and decisions in GitHub issues. Use a feature branch and pull request for changes, and include a short description and verification steps so another contributor can pick up the work.

Keep real client and staff records, care documents, credentials and environment secrets out of the repository, issues, pull requests and previews.
